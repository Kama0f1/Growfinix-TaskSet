# Project 1 — Campus Cloud static website

A responsive student resource page with plain HTML and CSS. It demonstrates static cloud hosting and content delivery without a database or server code.

## Run locally

Open `index.html` in a browser. Internet access is only needed for the optional links and Google Fonts; the page itself is local.

## Deploy on Vercel

1. Put this folder in a GitHub repository (or select this folder when using the Vercel CLI).
2. In Vercel, import the repository and set the project root to `task1` if the repository contains the whole Growfinix folder.
3. Choose **Other** / static output, leave the build command empty, and deploy.
4. Open the generated URL on a phone or another browser and save a screenshot.

## Explain it simply

HTML and CSS are static files. Vercel stores a deployment and serves those files through its delivery network. Because there is no database or long-running server, this project is easy to deploy and maintain. A code change creates a new deployment; a preview URL can be checked before production.
